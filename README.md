# 魔法粒子 Magic Particle

> 一个纯前端、零依赖的「图片 / 文字 / 词云 → 3D 粒子」交互工具。所有处理都在你的浏览器本地完成，图片与文字**不会上传到任何服务器**。

把任意一张照片、一段文字，或一个词云，逐像素拆成数十万个带原色的粒子，再用 3D 投影渲染成可以旋转、缩放、做空间视差的交互画面。类苹果「空间照片」的倾斜感、深度图驱动的真正 3D、文字/词云的厚度挤出——都能在这里玩到。

---

## ✨ 功能特性

### 三种素材来源
- **图片**：拖拽（全窗口任意位置）或点击导入，支持 PNG / JPG / WEBP / GIF / BMP / SVG。
- **文字**：直接输入文字即可生成粒子（无需上传文件），自带横向彩虹渐变与波动起伏。
- **词云**：输入多个词（空格 / 逗号 / 换行分隔），按 **Python `wordcloud` 同款算法**——词频定字号、大词优先、螺旋紧密排布 + 逐像素碰撞检测、偶尔竖排——生成错落有致的词云，再转粒子。

### 精度档位（决定粒子数）
| 档位 | 最长边粒子数 | 预估粒子数（3:2 图） |
|---|---|---|
| 低 | 64 | ~ 4k |
| 中（推荐） | 120 | ~ 14k |
| 高 | 180 | ~ 32k |
| 超高档 | 280 | ~ 78k |
| 极限档 | 420 | ~ 176k |
| 自定义 | 32 – 800（可调，含实时预估） | 随输入变化 |

### 立体与厚度
- **厚度挤出**：文字 / 词云模式下可设厚度（0–16），字形沿 z 轴多层挤出、后退层变暗，形成真 3D 体积。
- **真实深度图**：图片模式可接入由 Depth-Anything / MiDaS / ZoeDepth 等单目深度模型生成的灰度深度图，粒子的前后位移由真实深度驱动（越亮越靠前），旋转时是真正的 3D 照片视差。不喂深度图时自动回退到「亮度伪深度」。

### 预览交互（全部在 `render.ts` 风格的渲染循环里）
- **鼠标排斥**：光标靠近的粒子被推开并放大，离开后自动归位。独立面板可调 **受力范围 / 力度 / 靠近放大**。
- **3D 照片模式**：类 Win10 按钮的倾斜感——光标靠近时整团粒子明显朝那一侧倾斜并轻微放大；按住拖拽自主旋转，滚轮缩放，移开后按可调速度回正。
- **自动旋转**：速度可调（含 0 = 停）。
- **粒子大小 / 缩放 / 立体景深** 滑块。
- **FPS 显示**：预览右上角实时显示粒子数与帧率。
- **导出 PNG**：一键导出当前画面。

### 其它
- **AI 提示词框**：在「使用深度图」下方，提供可直接复制到 Midjourney / Stable Diffusion 的提示词（强调前后景深，利于深度估计），带「复制」与「随机示例」。
- **全窗口拖拽上传**：拖文件到页面任意位置即上传，带全屏「释放以导入」遮罩。
- **明暗双主题**：默认暗色（贴合 IDE），可切换并 localStorage 记忆。
- **顶部进度条可点击退回**：`$ 定义` / `$ 精度` / `$ 预览` 任意跳转（未生成时禁止跳预览）。
- **终端 UI 风格**：macOS 窗口、等宽字体、暖陶土色主色，全程中文界面。
- **无障碍**：ARIA 标签、键盘导航、focus 环、`prefers-reduced-motion` 支持。

## 🛠 技术栈

- 纯原生 **HTML + CSS + JavaScript**，无任何构建步骤、无框架、无外部依赖。
- 渲染基于 **Canvas 2D** + 自写 3D 投影与深度排序（画家算法），脏标记驱动渲染，空闲不重绘。
- 图片处理用 `Canvas` + `getImageData` 逐像素读取颜色；文字/词云用离屏 Canvas 绘制后采样。

### 目录结构
```
图片粒子/
├── index.html   # 页面结构（终端窗口、模式切换、控制面板、关于）
├── styles.css   # 终端风样式、明暗主题、响应式
├── app.js       # 全部逻辑：导入/精度/生成/渲染/交互
└── README.md    # 本文件
```

## 🚀 快速开始

1. **直接打开**：双击 `index.html` 即可运行（纯前端，无需服务器）。
2. 或本地起服务：
   ```bash
   python -m http.server 8000
   # 浏览器访问 http://127.0.0.1:8000
   ```

### 使用流程
1. **定义**：选择「图片 / 文字 / 词云」，导入或输入内容；图片模式可在此勾选「使用深度图」并填 AI 提示词去生成源图。
2. **精度**：选档位或自定义，可选「厚度」（文字/词云），点「开始生成」。
3. **预览**：拖拽旋转、滚轮缩放、开鼠标排斥 / 3D 照片，调参后导出 PNG。
